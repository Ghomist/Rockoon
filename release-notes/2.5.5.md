## 新增

- TAS 编辑器：`Shift` + 滚轮 = 快速滚动，速度是普通滚动的 4 倍（横版左右、竖版上下都适用）
- TAS 编辑器：复制 / 粘贴按轨道走，可以直接贴回同一条轨，不再被压短
- TAS 编辑器：「整理动画」把按住不放的段补齐成逐帧按键，「自由观看」反过来把逐帧按键合并成按住
- 启动器：更新弹窗按「新增 / 修改 / 删除」分段显示本次更新内容

## 修改

- TAS 编辑器：跳上 / 下一段改用 `Esc`（原来的组合键在部分键盘上按不出来）；无选区时方向键跨整段，`[` / `]` 也是跳段
- TAS 编辑器：文件列表里空的或已不存在的 `.tas` 也会列出（但不可点击）
- TAS 编辑器：说明条和帮助里的滚轮说明跟着改成「Shift + 滚轮 = 快速滚动」
