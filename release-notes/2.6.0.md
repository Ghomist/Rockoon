## 新增

- 支持 macOS：游戏通过 Wine 运行，启动器自己准备 Wine 运行环境，不用另外装
- macOS：Apple 芯片上缺 Rosetta 2 时可以一键安装
- 设置页：新增「Wine 运行环境」，可以查看状态、换用别的位置或重装
- macOS：窗口改用系统原生的红绿灯按钮

## 修改

- Windows 安装包和以前一样，不包含 Wine 相关内容
- macOS 上游戏起不来会自动重试（最多 8 次），启动期间有「正在启动」提示，不会点一下就开两个
- 修了原版自带的一个按键重复问题：电脑连续开机超过 24.8 天后，游戏里输入名字会按一下出一串字（只改原版自带的那个文件，改之前会留一份 `.orig` 备份）
- macOS 上 Option 键可以当 Alt 用，游戏里的 Alt+F4 / Alt+Enter 正常了

## 删除

- macOS 不再需要手动指定 Ballance.app 或 WineHQ 的 Wine，Wine 随启动器下载好、用完即走，运行时不再访问 GitHub
